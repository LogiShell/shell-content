# Контент-студия

LogiShell shell для коротких роликов и постов в соцсетях.

* **Идеи**: копилка идей, Claude придумывает пачку по теме блога.
* **Сценарий**: Claude пишет сценарий ролика (зацепка, сцены, закадр, подпись, хэштеги), всё правится руками.
* **Видео**: собирает вертикальный ролик 1080×1920 из сцен прямо в браузере, с фоном и музыкой, и отдаёт файл.
* **План**: что и когда выходит, подпись копируется одной кнопкой.
* **Данные**: вход через LogiShell или свой ключ Anthropic, выгрузка и загрузка всего одним файлом.

Открыть: https://shell.lsh.dev/s/LogiShell/shell-content

Всё, что вводится, хранится только в браузере того, кто открыл shell.
